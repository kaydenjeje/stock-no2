# 주식 스크리닝 정보 서비스 리뉴얼 기획안 (v1)

> 기반 코드: `stock-no1` (Streamlit, Gemini/DeepSeek 기반 AI 주식 추천 대시보드)
> 본 문서는 화면 기획서이며, `stock-no1`은 수정하지 않고 신규 구현은 `stock-no2`에서 진행한다.

---

## 0. 배경 및 방향 전환

기존 `stock-no1` 앱은 아래 두 기능 때문에 유료화 시 자본시장법상 **유사투자자문업 신고 대상**이 될 가능성이 높다.

1. 종목별 **구체적 매수가·목표가(+5%)·손절가(-3%)** 제시
2. 종목별 **개인 맞춤 AI 챗봇 상담** ("갭상승 시 대응법은?" 등 개별 질의응답)

신고 없이 유료화하려면 문구만 바꾸는 우회가 아니라, **서비스의 실질을 "투자판단 조언"에서 "객관적 데이터/스크리닝 툴"로 실제로 바꿔야 한다.** 아래 기획은 그 원칙 위에서 화면 단위로 다시 설계한 것이다.

⚠️ 이 기획대로 구현해도 법적 리스크가 0이 되는 것은 아니며, 최종 문구/기능 확정 후 출시 전 변호사 검토를 권장한다.

## 3. 화면별 상세 기획

### 3-1. 스크리닝 대시보드 (구 목록화면 대체)

- 상단 스코어보드(시장온도, 섹터별 분포)는 유지, 문구만 조정
- **카드 항목 변경**

  | 기존 | 변경 |
  |---|---|
  | 권장 매수가 72,500~73,000원 | *(삭제)* |
  | 1차 목표가 76,650원 (+5%) | *(삭제)* |
  | 손절 기준가 70,800원 (-3%) | *(삭제)* |
  | 모멘텀 스크리닝 점수 85점 | 유지 |
  | — | 스코어 구성요소 배지 추가: `20일선 상향돌파` `거래량 180%` `외국인 5일 순매수` |
  | "✨ 심층 분석 AI 리포트 보기" 버튼 | "📊 지표 상세보기" 버튼 |
- **필터/정렬 강화** (스크리너 성격 강화 = 유료 전환 포인트): 섹터, 스코어 구간, 정렬 기준(스코어순/등락률순/거래량순/수급순)
- **Freemium 경계**: 무료는 스코어 상위 5개만 노출, 유료는 20개 전체 + 필터/정렬 기능 오픈

### 3-2. 종목 상세 데이터 화면 (구 상세화면 대체)

- 차트/거래량/이동평균 등 **사실 데이터 표시부는 그대로 유지** (조언이 아니므로 문제 없음)
- "AI 고도화 종합 리포트 생성" → **"AI 지표 해설 생성"**으로 성격 전환
  - 4개 에이전트 프롬프트에서 `투자의견(강력매수/매수/관망/매도)`, `권장 매수 구간`, `목표가`, `손절 기준가` 산출 항목을 **전부 제거**
  - 대체 산출물: 이동평균 배열 상태 설명 / 거래량 급증의 기술적 의미 / 수급 동향 요약 / 뉴스 감성 스코어 — "~하는 편이 유리하다" 류 표현 없이 사실 서술형으로만 작성하도록 프롬프트 재작성
- **챗봇("추가 질문하기") 처리 — 둘 중 택1**
  - **A안 (가장 안전, 권장)**: 기능 자체 제거
  - **B안**: "지표 용어/개념 설명" Q&A로 한정. 시스템 프롬프트에 "특정 매수/매도 타이밍이나 목표가를 답하지 말 것"을 강하게 명시하고, 종목 타이밍성 질문 감지 시 정형 거절 응답(예: "본 서비스는 투자 조언을 제공하지 않습니다")으로 자동 전환하는 가드레일 추가

### 3-3. 관심종목 / 알림 설정 (신규 — 핵심 수익화 축)

- 관심종목 등록 + 조건 알림(스코어 급변, 거래량 급증, 이평선 크로스) 이메일/푸시 발송
- "조언"이 아니라 "조건 알림 툴"이라 법적으로 더 안전하고, SaaS형 유료 기능으로 자연스럽게 붙는 지점

### 3-4. 요금제 / 구독 화면 (신규)

| 플랜 | 제공 범위 |
|---|---|
| Free | 스코어 TOP 5, 기본 차트 |
| Pro (구독) | 스코어 TOP 20, 전체 필터/정렬, 관심종목 알림, AI 지표 해설 생성(월 크레딧제) |

- 이용약관에도 "본 서비스는 투자자문이 아닌 데이터/스크리닝 도구 이용료"임을 명시

### 3-5. 로그인 / 마이페이지 (신규)

- 이메일 로그인, 구독 상태, AI 해설 생성 사용량 확인 (남용 방지 겸 과금 근거)

## 7. 참고 사례: hatzze.fun 벤치마킹

개인 개발자가 만든 [hatzze.fun](https://hatzze.fun/)은 코스피 시장의 "과열도"를 25개 지표(시장 지표 15 + 감성 지표 10)로 종합해 매일 0~100 온도계로 보여주는 서비스다. **개별 종목 매수/매도 추천이 전혀 없고 전부 시장 전체 또는 객관적으로 계산 가능한 데이터**로만 구성돼 있어, 본 기획의 "정보/스크리닝 툴" 방향성과 정확히 맞닿아 있는 실제 사례다.

### 7-1. 무엇을 제공하는 사이트인가

- 좌측 메뉴: 시장 브리핑 / 카더라 리포트 / 국장 카더라 / 미장 카더라(준비중) / MDD 청산분석 / 서학개미 재무제표(준비중)
- 상단: **햇비 지수**(0~100 과열도를 온도로 환산한 종합 지수) + 지표 분포(저온/보통/고온/초고온 개수) + "오늘의 브리핑" 자연어 요약 문단
- 본문: 지표 카드 그리드 — 코스피 신고가 대비 괴리율, 거래대금 집중도, VKOSPI, 버핏지수, 레버리지·신용 잔고 지수 같은 정통 지표뿐 아니라 재테크 유튜브 조회수·명품 검색량·경제 베스트셀러 비율·깃헙 트레이딩봇 생성 수·증권 앱 인기순위 같은 **대체 데이터(alternative data) 기반 감성 지표**까지 포함
- 하단: 데이터 출처 표, "재테크 참고용 정보만 제공하며 투자 판단 책임은 이용자에게 있습니다" 면책 문구
- 화면상으로는 결제/구독 화면이 보이지 않음 — 유료화 여부·모델은 확인되지 않았고, 광고/후원 등 다른 방식일 가능성도 있음. 따라서 "이 형태면 유료화해도 안전하다"는 근거가 아니라 **"조언 없이도 매력적인 콘텐츠 제품이 성립한다"는 제품 형태의 증거**로만 참고한다.

### 7-2. 본 기획에 반영할 요소

| hatzze.fun 패턴 | 본 서비스 적용 방안 |
|---|---|
| 카드 하단의 "~할수록 ~라는 뜻입니다" 해석 문장 (행동 지시가 아닌 의미 설명) | §3-2 "AI 지표 해설" 프롬프트 톤의 기준 문장으로 채택 |
| 종합 "온도" 지수 하나로 오늘 시장 상태를 요약 | §3-1 상단 "시장 종합 온도" 카드를 다지표 종합 온도계 형태로 확장 |
| "오늘의 브리핑" 자연어 요약 문단 | AI가 여러 지표를 묶어 사실 서술형 문단을 생성하는 방식 — §3-2 지표 해설 생성 로직에 참고 |
| 시장 지표 / 감성 지표 섹션 분리 | §3-1·3-2에서 기술적 지표와 뉴스·커뮤니티 감성 지표를 명확히 구분 표시 |
| "새로운 지표 제보하기" 커뮤니티 참여 기능 | 저비용 유저 참여/콘텐츠 아이디어로 후속 단계에 검토 |
| 데이터 출처 표 + 면책 문구 하단 고정 배치 | §0·§5의 법적 고지 상시 노출 원칙에 레이아웃 참고 |

### 7-3. 주의

hatzze.fun의 지표들은 개별 종목이 아니라 **시장 전체**를 대상으로 하는 것이 대부분이라 법적 리스크가 우리보다 낮다. 우리는 종목별 스코어를 계속 다루므로 이 패턴을 그대로 가져오더라도 §4 문구 가이드라인(금지어 목록)은 동일하게 적용해야 한다.

## 8. 초보자 타겟 유료 구독 심화 기획 (월 9,900원)

### 8-0. 전제

- §1~§7의 원칙(개별 종목 매수/매도가 미제시, 조언성 표현 금지)은 그대로 유지한다.
- 타겟을 "초보자"로 좁히면 두 가지가 달라진다.
  1. 가치제안이 "정보 제공"에서 **"이해하기 쉬운 정보 + 학습 + 습관화 도구"**로 이동해야 유료 전환이 설명된다.
  2. 초보 투자자를 명시적으로 겨냥한 유료 마케팅이므로, 유사투자자문업 이슈와 별개로 **금융소비자보호법상 취약계층 보호·과장광고** 이슈에 더 민감해진다.

### 8-1. 타겟 페르소나

- 이제 막 계좌를 텄지만 HTS/MTS의 숫자가 너무 많아 뭘 봐야 할지 모르는 사람
- 유튜브·오픈채팅방 "카더라"로 종목을 산 경험이 있고, 스스로 판단하는 눈을 기르고 싶은 사람
- → 이들이 진짜 원하는 건 "찍어주는 것"이지만, 우리가 합법적으로 팔 수 있는 것은 **"이해하는 법 + 매일 확인하는 습관 + 커리큘럼"**이다. 이 간극을 인정하고 제품을 설계해야 한다.

### 8-2. 핵심 가치제안 재정의 — 왜 9,900원을 내는가

지표의 "의미" 자체는 검색하면 무료로도 나온다. 결제 이유는 지식이 아니라 아래 네 가지다.

1. **번역**: 복잡한 지표를 매일 초보자 언어로 자동 요약해주는 반복적 편의
2. **습관화**: 관심종목 지표를 매일 알림으로 받아 "확인하는 루틴"을 만들어주는 것 (콘텐츠가 아니라 습관 서비스)
3. **커리큘럼**: 순서대로 따라가면 시장을 읽는 눈이 생기는 학습 경로
4. **정제된 경험**: 유튜브·주식카페의 노이즈·과장 없이 광고 없는 화면

### 8-3. 신규/보강 기능

| 기능 | 내용 | 비고 |
|---|---|---|
| **A. 온보딩 진단** (신규) | 가입 시 5문항 레벨 체크("이동평균선이 뭔지 아세요?" 등) → 레벨별 학습 순서 추천 | 종목이 아닌 "콘텐츠" 추천이라 안전 |

| **C. 초보자용 홈 대시보드** (§3-1 보강) | 시장온도·브리핑을 쉬운 말로 재작성, 모든 숫자에 "왜 중요한가요?" 툴팁 | |
| **D. 관심종목 알림** (§3-3 보강, 유료 핵심) | 지표 변화를 **사실 그대로** 알림. 예: "OO전자 20일선이 5일선을 상향 돌파했어요"(O) / "OO전자 매수 타이밍이에요"(X) | Free 1개 / Pro 무제한+실시간 |
| **E. 매매 저널** (신규) | 사용자가 스스로 매매를 기록하면, 그 시점 객관 지표(스코어·이평선 상태)를 자동으로 붙여 나중에 복기 | 서비스가 판단을 주는 게 아니라 유저가 스스로 복기 → 안전하고 리텐션에 기여 |
| **F. 리스크 코칭 콘텐츠** (신규) | 분산투자, 손절 규칙을 왜 미리 정해야 하는지, 뉴스에 흔들리지 않는 법 등 **일반 원칙 교육** | 특정 종목·시점 언급 없음 → 조언성 리스크 낮음 |

### 8-5. 온보딩 → 결제 전환 플로우

1. 무료 가입 → 진단 → 맞춤 학습경로 시작
2. 관심종목 2번째 등록 시도 시 "Pro는 무제한" 업셀 노출
3. 7일 무료체험 → 자동 유료전환 (전환 전 사전 고지 필요, 8-6 참고)

### 8-6. 구독 결제 관련 추가 유의사항 (유사투자자문업과 별개)

정기결제(구독) 자체에도 지켜야 할 소비자보호 규정이 있다.

- 전자상거래법상 정기결제는 **결제 전 고지, 해지 방법 명시, 청약철회(7일 이내 환불)** 규정을 지켜야 한다.
- 무료체험 → 자동 유료전환 방식은 전환 전 별도 고지(문자/이메일 등)가 사실상 필수 관행이다.
- "초보자"를 명시적으로 겨냥한 마케팅은 금융소비자보호법상 취약계층 보호 이슈로 더 엄격히 볼 수 있다.
- 통신판매업 신고 대상 여부 등, 이 부분도 최종 상품화 전 확인이 필요하다 (§5의 변호사 검토 범위에 포함).
